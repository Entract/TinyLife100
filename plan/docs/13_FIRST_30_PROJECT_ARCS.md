## Reading integration rule

Each project arc should identify **knowledge gaps that might plausibly trigger external reading**, but no project is required to include a book. Source encounters should vary naturally:

- component datasheet;
- tool/manual;
- textbook chapter;
- documentation;
- paper;
- code/example;
- recommendation from a person;
- later rereading.

The project arc remains the causal backbone. Reading is one acquisition mode among several.
